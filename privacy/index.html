سياسة الخصوصية

تاريخ السريان: 29 سبتمبر 2026 • النطاق الرسمي: zaadsystem.com • التواصل: support@zaadsystem.com

1. نظرة عامة وملكية البيانات

تحكم سياسة الخصوصية هذه عمل برنامج ZAAD POS (zaadsystem.com)، المطوّر والمملوك بواسطة جهاد قابل. تظل جميع معاملات المتجر والمخزون وحسابات العملاء والموردين وسجلات الورديات والملخصات المالية مخزنة بنسبة 100% محلياً على جهاز الكمبيوتر الخاص بك.

2. بنية التخزين المحلي

يتم تخزين كافة بيانات المتجر محلياً داخل قاعدة بيانات SQLite مدمجة على القرص الصلب للمتجر. لا يلزم أي مزامنة سحابية أو استضافة خوادم خارجية لتشغيل المحل.

3. إفصاحات الربط بـ Google API و OAuth 2.0

يوفر ZAAD POS ميزة اختيارية تتيح لمالكي المتاجر تلقي تقارير Z اليومية المؤتمتة مباشرة عبر البريد الإلكتروني باستخدام نطاق الصلاحية https://www.googleapis.com/auth/gmail.send.

تُستخدم صلاحية Gmail حصرياً لإنشاء وإرسال تقارير Z اليومية الصادرة فقط. لا يقوم ZAAD POS بقراءة أو مسح أو فحص محتويات صندوق الوارد نهائياً. يتم تخزين رموز اعتماد Google محلياً على القرص الصلب لجهازك فقط.

4. التحليلات والتتبع الخارجي

لا يتضمن نظام ZAAD POS أي برمجيات تتبع تابعة لجهات خارجية أو متتبعات إعلانية أو بكسلات تتبع أو ملفات تعريف ارتباط سلوكية.
