Data Ownership & Security

Local Data Storage & Privacy Transparency

ZAAD POS prioritizes local data sovereignty. All critical store data—sales, inventory, customers, supplier accounts—is stored locally on the retail store's computer in a high-performance SQLite database.

100% Local Data Control No cloud database subscription or external server hosting required.
Optional Google OAuth Integration Store owners can optionally connect Gmail to receive automated Daily Z business reports.
Zero Inbox Reading or Data Selling Gmail access scope (gmail.send) is used strictly to send PDF reports. ZAAD POS never reads or scans user emails.

Google API Verification Notice

ZAAD POS requests restricted Gmail access solely for sending automated owner reports.

  • ✓ Scope requested: https://www.googleapis.com/auth/gmail.send
  • ✓ Credentials stored securely on local desktop disk
  • ✓ Revocable anytime via Google Account settings
